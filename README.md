Data analytics project analyzing agricultural performance across Kharif, Rabi, and Zaid seasons.
# 🌾 Seasonal Agriculture Performance Analysis

## 📌 Overview

This project analyzes agricultural performance across the three major farming seasons in India:

- Kharif
- Rabi
- Zaid

The project uses Python and data analytics techniques to analyze agricultural yield, profit, rainfall, water usage, and other factors.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## 📊 Analysis Performed

- Data Cleaning
- Exploratory Data Analysis
- Seasonal Analysis
- Crop-Wise Analysis
- State-Wise Analysis
- Correlation Analysis
- Profit Analysis
- Water Efficiency Analysis

## 📁 Files

- `Seasonal_Agriculture_Performance_Analysis.ipynb` — Complete analysis notebook
- `Seasonal_Agriculture_Performance_Analysis.pptx` — Project presentation
- `seasonal_agriculture_performance_dataset.xlsx` — Dataset
